# LevelPlay

曲ごとの音量差を自動でそろえて再生する、ブラウザで動く音楽プレイヤーです（個人用）。

- 曲ごとのラウドネス（EBU R128）を測り、目標値（既定 -14 LUFS）に合わせて固定のゲインをかけます。再生中に音量は変えません
- -1 dB のリミッターで音割れを防ぎます
- 読み込んだ曲はブラウザの中だけで処理し、どこにも送信・保存しません。閉じると一覧は空になります
- 対応形式: MP3 / WAV / FLAC / AAC / M4A / Ogg / Opus（Chrome / Edge 推奨）

ローカルで動かす場合は `LevelPlay.cmd` をダブルクリックします（`http://localhost:8765/`）。
